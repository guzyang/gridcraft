# GridCraft 0.19.1 v4：中文字体与粗体

这一版修的是「中文粗体不生效」和「从别的程序复制过来的粗体丢失」。

## 这一版改了什么

- **中文字体名认得出了**：工作簿里写「宋体」，这台机器上叫「宋体-简 / Songti SC」；以前名字对不上，
  单元格就退回通用字体。现在「宋体 / 黑体 / 楷体 / 仿宋 / 微软雅黑 / 等线 / 苹方 / 华文系列」
  都能找到本机对应的家族；Windows 独有的字体（微软雅黑等）用系统自带的中文家族顶上
- **粗体真的粗了**：中文（以及阿拉伯文、希伯来文、泰文、韩文）的粗体面现在按字重单独加载，
  不再拿常规字重的字来画——之前粗体单元格里的中文看着是细的
- **字体下拉列出本机真实装的字体**：以前只有 17 个写死的英文字体名，macOS 装的中文字体一个都选不到

## 使用说明（macOS 未签名版）

1. 下载 release 里的 `gridcraft-0.19.1-v4-macos-aarch64.dmg`（Apple Silicon：M1/M2/M3/M4/M5）
2. 终端里解除隔离标记（不需要密码）：
   `xattr -dr com.apple.quarantine ~/Downloads/gridcraft-0.19.1-v4-macos-aarch64.dmg`
3. 双击 dmg，把 GridCraft 拖进 Applications
4. 第一次打开：在 GridCraft 上右键 → 打开 → 再点「打开」

别点应用自己的「更新」提示：一更新就换回官方版，本页这些改动就没了。
