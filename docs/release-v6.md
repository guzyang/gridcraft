# GridCraft 0.19.1 v6：外部引用真同步 + 循环引用按 Excel 显示

## 这一版改了什么

### 1. 引用别的表格文件，现在会自动跟随

打开一个引用了其他 `.xlsx` 的文件时，GridCraft 会按链接里记录的目标去读那个文件：

- 目标可以是相对路径、绝对路径、`file://` 地址，或者 Windows 反斜杠写法；
- 读到之后用源文件的当前值，并把读了这些值的单元格重新算一遍（依赖会跟着更新）；
- 源文件找不到时，保留文件里上次保存的值并在链接列表里标出来（和 Excel 一样，不报错）。

`Data > Links` 里能看到每条链接指向哪个文件、读的是哪张表的哪个单元格、源文件在不在；
可以**更改源**（换一个文件）和**断开链接**（保留当前值，去掉公式）。

### 2. 三种写法都能输入、都能算

- `[1]SheetList!A1`（文件里的索引写法）
- `'[Book2.xlsx]Sheet1'!A1`（公式栏里的文件名写法）
- `'C:\dir\[Book2.xlsx]Sheet1'!A1`（带路径）

都会解析、计算，并且保存回文件时**原样写回**——回到 Excel 里链接还是活的。

### 3. 循环引用按 Excel 的规则显示

公式绕成环（比如 A1 引用 B1、B1 又引用 A1）时，环上的单元格现在显示 **0**，其它单元格用这个 0 正常计算；
`公式 > 错误检查` 的循环引用列表仍然会列出这些单元格。以前会给 `#CIRC!` 并把错误传给下游，看上去像"整块链接都断了"。

## 安装

下载 dmg，拖进「应用程序」。未签名版本第一次打开需要右键 →「打开」，
或者执行：`xattr -dr com.apple.quarantine /Applications/GridCraft.app`

## 已知限制

- 只读取被链接文件的**值**，不读它的公式（Excel 刷新也是取结果）。
- 保存时单元格的值会更新；链接部件里那份缓存值要等 Excel 自己刷新时才同步。
- 超过求值栈深度的超长环（几百个单元格互相引用），只在环闭合处取 0。
